## 📖 项目简介

`OpenExplorer` 是一个纯粹为了**“物理意义脱衣”**而生的 Windows 命令行工具。

当你的 Windows 11 遭遇 `/moteoxd` 基因突变、丢失了 `dwm.exe`、`sihost.exe` 和所有 `Windows.UI.*` 后，系统会退化成纯文本的 TUI 状态（即 LogonUI 变成了 TUI，满屏报错 `0x233c` 甚至 `0x233o`）。

在系统崩溃、图形界面彻底瘫痪的赛博废土世界里，你只能依靠 `cmd.exe` 和 `echo` 续命。此时，`OpenExplorer` 就是你的急救包——它是一个不依赖桌面环境（Explorer.exe）的纯 Win32 API 文件选择器。
